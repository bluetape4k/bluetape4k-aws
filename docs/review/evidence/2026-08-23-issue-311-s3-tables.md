## 테스트 계약

- Java sync, `CompletableFuture`, coroutine `.await()`와 Kotlin suspend 각각에서
  table bucket·namespace·table create/list/get/delete 12개 operation의 raw response와
  request field delegation을 확인한다.
- request DSL은 callback 적용 이후 required identifier, `CreateTable.format=ICEBERG`,
  `GetTable` selector XOR, continuation token/max 값을 최종 검증한다.
- Java/Kotlin lifecycle은 성공·예외·cancellation에서 service client close를 확인하고,
  caller-owned HTTP client/engine을 닫지 않는 계약을 확인한다.
- smoke는 `s3-tables-read-only-smoke`와 `s3-tables-mutating-smoke` tag로 분리한다.
  mutating lane은 첫 생성 전 STS account ID를 비교하고, 이번 실행이 만든 resource만
  timeout·역순 cleanup한다. 필요한 환경 변수가 없으면 Gradle task가 client 생성 전에 skip한다.
