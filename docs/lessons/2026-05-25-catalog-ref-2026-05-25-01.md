# Catalog Ref 2026-05-25-01 적용

## 배경

공통 `bluetape4k-dependencies` 카탈로그에서 ASM, AWS Kotlin SDK, Apache Fory
의존성을 갱신했다.

## 결정

기본 `bluetape4kDependenciesCatalogRef`가 `develop`을 따라가지 않도록
`catalog/2026-05-25-01`로 고정한다.

## 결과

이제 Gradle settings는 기본적으로 릴리스 트레인 카탈로그를 가져오며,
`bluetape4kDependenciesCatalogRef` 또는 `BLUETAPE4K_DEPENDENCIES_CATALOG_REF`로
재정의할 수도 있다.

이제 스냅샷 게시 workflow는 `develop`을 강제로 checkout하는 대신 dispatch한 ref를
checkout한다. 따라서 branch gate를 거치는 스냅샷 트레인 검증에서는 Nightly를 통과한
것과 같은 카탈로그 고정 소스를 게시한다.

## 검증

- Settings 파일을 `catalog/2026-05-25-01`로 갱신했다.
- `./gradlew compileTestKotlin --refresh-dependencies --console=plain -PsnapshotVersion=-SNAPSHOT`
- `actionlint .github/workflows/publish-snapshot.yml`

## 향후 보호 장치

조율된 의존성 트레인 갱신에는 날짜가 포함된 카탈로그 태그를 사용한다. 수동으로
dispatch한 스냅샷 게시 workflow에서 `develop` checkout을 강제하지 않는다. 검증과
게시가 같은 소스 트리를 사용하도록 dispatch ref를 사용한다.
