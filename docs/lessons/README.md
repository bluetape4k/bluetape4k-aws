# 교훈

지속해서 참고할 `bluetape4k-aws` 교훈을 이 디렉터리에 기록합니다.

각 교훈은 다음 구조를 사용합니다.

- 배경
- 결정 또는 발견 사항
- 결과
- 검증
- 향후 지침

파일 이름은 `YYYY-MM-DD-{slug}.md` 형식을 사용합니다. 반복되는 규칙은 `AGENTS.md`,
workflow 문서 또는 더 좁은 범위의 skill로 승격합니다. 일시적인 `.omx` note는 의도적으로
승격한 경우가 아니면 이 디렉터리에 두지 않습니다.
