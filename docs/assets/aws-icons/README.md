# AWS Architecture Icons

이 디렉터리는 README 다이어그램에 사용할 공식 AWS Architecture Icons package에서
추출한 SVG 자산을 저장한다.

출처:
https://aws.amazon.com/architecture/icons/

package:
`Icon-package_04302026.4705b90f5aa45b019271a2699e9ce9b97b941ee1.zip`

포함 내용:

- `official-04302026/Architecture-Service-Icons_04302026/**/*.svg`
- `official-04302026/Resource-Icons_04302026/**/*.svg`

SVG 파일만 이곳에 저장한다. repository 크기를 줄이고 생성된 SVG 다이어그램에서
icon을 재사용할 수 있도록 PNG 파일과 원본 ZIP은 의도적으로 제외한다.

다이어그램 사용 규칙:

- AWS service와 resource에는 이 공식 AWS SVG path를 우선 사용한다.
- 생성한 다이어그램 텍스트는 `Architects Daughter`와 `Comic Mono`으로 유지한다.
- 저장된 공식 SVG 파일을 직접 편집하지 않는다. 다이어그램에 더 작은 icon이
  필요하면 복사한 path를 다이어그램 SVG에 inline하고 그곳에서 크기를 조정한다.
