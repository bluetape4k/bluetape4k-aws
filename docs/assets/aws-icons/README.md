# AWS Architecture Icons

This directory stores SVG assets extracted from the official AWS Architecture
Icons package for README diagrams.

Source:
https://aws.amazon.com/architecture/icons/

Package:
`Icon-package_04302026.4705b90f5aa45b019271a2699e9ce9b97b941ee1.zip`

Included:

- `official-04302026/Architecture-Service-Icons_04302026/**/*.svg`
- `official-04302026/Resource-Icons_04302026/**/*.svg`

Only SVG files are stored here. PNG files and the original ZIP are intentionally
excluded to keep the repository smaller and to make the icons reusable inside
generated SVG diagrams.

Diagram usage rules:

- Prefer these official AWS SVG paths for AWS services and resources.
- Keep generated diagram text in `Architects Daughter` and `Comic Mono`.
- Do not edit the stored official SVG files directly. If a diagram needs a
  smaller icon, inline a copied path into the diagram SVG and scale it there.
