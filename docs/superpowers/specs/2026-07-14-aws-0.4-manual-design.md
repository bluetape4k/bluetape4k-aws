# AWS 0.4 Source Manual Design

## Goal

`bluetape4k-aws`가 직접 소유하는 이중 언어 매뉴얼을 만들고, `0.4.0` 릴리스에 실제로 포함된 모듈과 소스만 웹사이트에 공개한다. README는 빠른 소개로 유지하고, 매뉴얼은 선택 기준, 운영 책임, 서비스별 학습 경로, 프레임워크 통합, 예제까지 설명하는 source of truth가 된다.

## Release authority

```yaml
repository: bluetape4k/bluetape4k-aws
releaseRef: 0.4.0
releaseCommit: be4e6daea5654f84579955307ec56a58c8f405be
minorVersion: "0.4"
releaseModuleCount: 14
excludedDevelopOnlyModules:
  - aws-ktor-service-coverage-examples
```

현재 `develop`에는 15개 Gradle 프로젝트가 있지만 `aws-ktor-service-coverage-examples`는 `0.4.0` 태그에 없다. 0.4 매뉴얼과 생성 manifest는 릴리스 트리에서 확인되는 14개 프로젝트만 포함한다.

## Information architecture

1. 시작하기: 사용자는 `bluetape4k-dependencies` 버전만 선택하고, 실제 사용하는 AWS 서비스 SDK를 런타임 의존성으로 추가한다.
2. SDK 선택: AWS SDK for Java v2와 AWS SDK for Kotlin의 차이, coroutine 사용 방식, client lifecycle을 설명한다.
3. 핵심 라이브러리: `aws-java`, `aws-kotlin`, `aws-exposed`의 역할과 경계를 설명한다.
4. 프레임워크 통합: Spring Boot 자동 설정과 Ktor plugin/runtime을 비교한다.
5. 서비스별 학습 경로: S3, DynamoDB, SQS/SNS를 실제 예제와 함께 순서대로 익히게 한다.
6. 데이터베이스 확장: Secrets Manager/Parameter Store/RDS IAM에서 Hikari와 Exposed로 이어지는 경로를 독립 주제로 다룬다.
7. 테스트와 운영: Floci를 기본 emulator로 사용하고, LocalStack fallback, endpoint override, 자격 증명, 재시도, 관측성, client 종료 책임을 설명한다.
8. 예제: 릴리스에 포함된 8개 예제를 workshop 수준의 학습 자료로 연결한다.

## Content depth

- 모든 릴리스 프로젝트에는 영문·한글 landing page가 있다.
- `bluetape4k-aws-java`, `bluetape4k-aws-spring-boot`, `bluetape4k-aws-ktor`, `bluetape4k-aws-exposed`에는 세부 chapter를 둔다.
- 한글은 영문 직역이 아니라 한국어 독자가 자연스럽게 읽는 문장으로 독립 교정한다.
- 소스 링크는 저장소 상대 경로로 기록하며, release validator가 `0.4.0` 트리에 존재하는지 검사한다.
- Projects와 Exposed 매뉴얼은 학습 확장 링크로 연결하되 AWS manifest의 릴리스 파일 계약에는 포함하지 않는다.

## Visual language

매뉴얼 diagram은 파스텔 톤을 쓰지 않는다. 짙은 배경, 높은 명도 대비, 충분한 카드 폭, 선명한 연결선 색상, 읽을 수 있는 화살촉을 사용한다. SVG와 PNG를 함께 제공하며 checklist와 실제 렌더링 눈 검수를 모두 통과해야 한다.

## Publication contract

AWS 저장소의 `docs/manual/manifest.yaml`과 `docs/manual/generated/manifest.json`이 원본이다. 웹사이트는 AWS PR이 병합된 뒤 깨끗한 source commit에서만 동기화하며 다음 provenance를 별도로 표시한다.

- release source: `0.4.0` / `be4e6daea5654f84579955307ec56a58c8f405be`
- authoring source: 매뉴얼 PR의 병합 commit
