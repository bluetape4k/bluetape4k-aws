# AWS 0.4 Source Manual Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development or executing-plans and complete each checkbox with fresh evidence.

**Goal:** Build a bilingual, release-faithful `bluetape4k-aws` 0.4 manual that covers all 14 Gradle projects present in release `0.4.0`, teaches AWS SDK and framework choices, and treats the released examples as first-class learning material.

**Architecture:** The source repository owns the YAML manifest, normalized JSON, bilingual Markdown, paired dark SVG/PNG diagrams, and Ruby validators. Gradle exports the current 15-project inventory; a release inventory filters the develop-only service-coverage example and pins every repository-relative reference to tag `0.4.0` at commit `be4e6daea5654f84579955307ec56a58c8f405be`.

**Tech stack:** Kotlin/Gradle, Ruby standard library and Minitest, YAML/JSON, Markdown, SVG/PNG, Git release-tree inspection
