# AWS 0.4 원본 매뉴얼 구현 계획

> **에이전트 작업자용:** 필수 하위 skill: subagent-driven-development 또는 executing-plans를 사용하고 각 체크박스를 최신 증거로 완료한다.

**목표:** `0.4.0` 릴리스에 포함된 Gradle 프로젝트 14개를 모두 다루고, AWS SDK와 프레임워크 선택 기준을 설명하며, 릴리스된 예제를 일급 학습 자료로 제공하는 이중 언어 `bluetape4k-aws` 0.4 매뉴얼을 구축한다.

**아키텍처:** 원본 저장소가 YAML manifest, 정규화된 JSON, 이중 언어 Markdown, 짙은 테마의 SVG/PNG 다이어그램 쌍, Ruby 검증기를 소유한다. Gradle은 현재 15개 프로젝트 인벤토리를 내보내고, 릴리스 인벤토리는 develop에만 있는 서비스 커버리지 예제를 제외한 뒤 모든 저장소 상대 참조를 commit `be4e6daea5654f84579955307ec56a58c8f405be`의 `0.4.0` 태그에 고정한다.

**기술 스택:** Kotlin/Gradle, Ruby 표준 라이브러리와 Minitest, YAML/JSON, Markdown, SVG/PNG, Git 릴리스 트리 검사
