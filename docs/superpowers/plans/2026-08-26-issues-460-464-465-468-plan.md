# AWS Spring Boot #460/#464/#465/#468 구현 계획

> **구현자 지침:** 이 계획은 승인된 Type A 설계를 순서대로 실행한다. 각 행동은 RED 테스트를 먼저 고정하고 GREEN 구현을 거친다. public GitHub·문서 prose와 commit message는 한국어로 작성한다.

**목표:** SQS listener, S3 transfer, CRT S3 client, DynamoDB Enhanced coroutine API의 네 운영 경계를 기존 bluetape 계약 위에 additive하게 제공한다.

**아키텍처:** #460은 기존 listener generation에 bounded admission과 FIFO group mutex를 붙인다. #464는 기존 transfer manager 앞에 threshold 기반 temp-file `S3OutputStream`과 Jackson3 converter/content resolver를 추가하고, #465는 그 transfer 경계를 조건부 CRT client로 선택한다. #468은 기존 Enhanced client/table resolver를 공유하는 `DynamoDbTemplate`으로 batch/transaction을 단일화한다.

**기술 스택:** Kotlin coroutines, Spring Boot 4 auto-configuration, AWS SDK v2 async/Enhanced APIs, MockK, bluetape4k assertions, ApplicationContextRunner, Floci 우선 Testcontainers.
