## Workflow 계약

- [x] **CL-01 — 콘텐츠나 다이어그램 변경 전에 체크리스트 작성**

  - **실패:** 문제를 수정하고 후속 검증을 반복한다.
- [ ] **CL-06 — 누락되거나 순서가 바뀐 작업 수정**
  - **조치:** 발견된 순서 차이를 수정하고 의존 검사를 갱신한다.
  - **증거:** 수정 기록 또는 차이가 없다는 명시적 결과.
  - **실패:** 전체 상태를 BLOCKED로 유지한다.
- [ ] **CL-07 — 되돌릴 수 없는 작업의 hold 갱신**
  - **조치:** 병합이나 공개 직전에 issue/PR 대상, CI, 담당자, label, milestone, branch를 다시 읽는다.
  - **증거:** 작업 시점의 실제 `gh`와 Pages 출력.

- [ ] **CL-08 — 완료 전 개수 확인**

  - **실패:** 완료를 주장하지 않는다.
