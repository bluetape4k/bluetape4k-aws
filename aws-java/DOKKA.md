# Module bluetape4k-aws-java

AWS Java SDK v2 integration module for bluetape4k. It keeps AWS SDK model types
visible while adding sync helpers, async `CompletableFuture` extensions, and
coroutine adapters for DynamoDB, S3, SES, SNS, SQS, KMS, CloudWatch, Kinesis,
EventBridge, STS, Secrets Manager, and Parameter Store.
